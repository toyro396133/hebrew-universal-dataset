# Directly authored corpus: batch A

Five independently written continuing worlds, 70 documents (5 per level) and 40 linked reference tasks. All source texts were written individually instead of being realized by the 14 reusable templates in the structured pilot. Domain settings: communal garden, message decoding, wind energy, stage lighting and cold-chain logistics. Split: train. License: CC0-1.0. Language review is still sampling-based; use as research-stage data.
