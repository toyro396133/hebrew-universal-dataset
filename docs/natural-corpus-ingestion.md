# קליטת קורפוסים טבעיים — Hybrid Corpus Ingestion

## עיקרון
קורפוסים חיצוניים משמשים לתשתית לשונית טבעית, ומאגר הדוגמאות המקוריות משמש למשימות הסקה, זיכרון והכללה מדידות. נתונים חיצוניים אינם מקבלים `level=1` רק מכיוון שנקלטו: **`level=0` פירושו לא מדורג**. 14 רמות היכולת נשארות 1–14.

## מצב מקורות
- **Hebrew Wikipedia Sentences**: כ־11 מיליון משפטים, CC BY-SA 3.0; מותר בשלב זה *staging בלבד*, עם ייחוס מדויק ברמת מאמר ו־dataset. נדרשת בדיקת תנאי הפרסום לפני העברה למאגר פתוח.
- **FineWeb2**: ODC-By 1.0 ובכפוף לתנאי Common Crawl ומקורות אינטרנטיים נוספים. מוגדר בקטלוג בלבד, **לא מאושר לקליטה אוטומטית**.

## הפעלה
בדיקה אופליין:
```bash
python scripts/ingest_corpus.py --fixture tests/fixtures/wiki-rows.jsonl --limit 25 --output-dir staging/example
python scripts/audit_staging.py staging/example
```
פיילוט חי — דורש גישה ל־Hugging Face:
```bash
python scripts/ingest_corpus.py --fetch --source hebrew_wikipedia_sentences --strategy spread --seed 17 --limit 2000 --scan-limit 10000 --output-dir staging/wiki-2000
python scripts/audit_staging.py staging/wiki-2000
```
אין להעתיק את `staging/` למאגר GitHub עד לביקורת פרטיות, זכויות, ייחוס והתאמת התוכן.

## שערי איכות
אורך, שיעור עברית, דוגמאות משובשות, כתובות רשת ופרטי קשר, כפילויות מדויקות וכפילויות קרובות בתוך המדגם, והשוואת חפיפה עם מסמכי validation/test הקיימים. הסינון אינו פותר פרטיות מלאה או זליגה סמנטית מתוחכמת; לעולם אין לטעון אחרת.

כל הנתונים החיצוניים נכנסים ל־`train` בלבד, קבוצות נקבעות לפי מאמרי מקור, וכל רשומה שומרת SHA של הטקסט המקורי, רישיון, גרסת מקור, ומידע ייחוס. אוצר מושגים או תוויות רמה אינם מוזרקים לטקסט המיועד למודל.

## מטרות המשך
בדיקות משפטים נרדפים והעתקת תבניות, בדיקת זכויות ברמת מקור, קליטת כמה מקורות בלתי תלויים, ביקורת אנושית, וניסויי הכללה מול עולמות סינתטיים שלא נחשפו באימון.
